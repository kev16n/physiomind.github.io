Corazón

1 Datos importantes del corazon




• Función principal es proporcionar oxígeno y nutrientes a los tejidos del cuerpo

• El corazón está compuesto por cuatro cavidades: dos aurículas en la parte superior y dos ventrículos en la parte inferior.

• El corazón tiene su propio sistema de conducción eléctrica que regula el ritmo y la coordinación de los latidos cardíacos.

• Aunque el corazón es responsable de bombear sangre a todo el cuerpo, también necesita su propio suministro de oxígeno y nutrientes. Las arterias coronarias, que se ramifican directamente desde la aorta, suministran sangre rica en oxígeno al tejido cardíaco.

Descripción del caso clínico



Usted es un médico general, el cual tiene una hija de 17 años llamada Laura Reyes. Su hija siempre ha sido una persona muy alegre y activa ya que pertenece al equipo regional de fútbol, le gusta salir de fiesta con sus amigos y realizar actividades de caridad. Pero usted ha estado un poco preocupado por ella ya ha notado que últimamente su hija se ha tenido que desvelar mucho por cumplir con entregas de la universidad, y de igual forma ha descuidado un poco sus hábitos en general por esto, pero ella dice que está bien así que usted lo deja pasar.




Usted se encuentra en el estadio de la ciudad viendo jugar a su hija en un partido de la liga regional de fútbol cuando empieza a notar a su hija un poco extraña. De repente ella se desploma en la cancha, teniendo que ser retirada del partido. Al reunirse con ella en la enfermería esta le confiesa que últimamente  estos desmayos repentinos le han sucedido de forma frecuente y que no se ha sentido muy bien de salud. Por lo cual usted decide llevarla a su consultorio para analizarla


Al llegar a su consultorio decide tomarle los signos vitales, donde encontró lo siguiente:


• Temperatura 37c°


• Frecuencia cardiaca variable entre 40 y 60 latidos por minuto


• Saturación de oxígeno normal


A base de esto usted tiene que tomar la decisión de qué examen realizar

#define USE_ARDUINO_INTERRUPTS true // Set-up low-level interrupts for most acurate BPM math.

#define USE_ARDUINO_INTERRUPTS true // Set-up low-level interrupts for most acurate BPM math.

// Variables

const int PulseWire = 0; // PulseSensor PURPLE WIRE connected to ANALOG PIN 0

const int LED13 = 13; // The on-board Arduino LED, close to PIN 13.

int Threshold = 550; // Determine which Signal to "count as a beat" and which to ignore.

// Use the "Gettting Started Project" to fine-tune Threshold Value beyond default setting.

// Otherwise leave the default "550" value.


PulseSensorPlayground pulseSensor; // Creates an instance of the PulseSensorPlayground object called "pulseSensor"



void setup() {


Serial.begin(9600); // For Serial Monitor


// Configure the PulseSensor object, by assigning our variables to it.

pulseSensor.analogInput(PulseWire);

(LED13); //auto-magically blink Arduino's LED with heartbeat.

pulseSensor.setThreshold(Threshold);


// Double-check the "pulseSensor" object was created and "began" seeing a signal.

(pulseSensor.begin()) {

Serial.println("SENSOR DE PULSO CARDIACO - YANATRONIC !"); //This prints one time at Arduino power-up, or on Arduino reset.

}

}




void loop() {


int myBPM = pulseSensor.getBeatsPerMinute(); // Calls function on our pulseSensor object that returns BPM as an "int".

// "myBPM" hold this BPM value now.


if (pulseSensor.sawStartOfBeat()) { // Constantly test to see if "a beat happened".

Serial.println("♥ Tu corazón esta latiendo "); // If test is "true", print a message "a heartbeat happened".

Serial.print("BPM: "); // Print phrase "BPM: "

Serial.println(myBPM); // Print the value inside of myBPM.

}


delay(10); // considered best practice in a simple sketch.


}
